Browser capture

Launch a browser with the ClipForge capture extension already loaded, so you do not have to install anything by hand.
Add it manually (step by step)
  1. Keep ClipForge running.
  2. Click Open extension folder below (or copy the path).
  3. In Chrome/Edge/Brave, go to chrome://extensions.
  4. Turn on Developer mode (top-right toggle).
  5. Click Load unpacked → pick the folder from step 2.
  6. Pin ClipForge (puzzle icon 🧩). Click it on any video page, or right-click → Add to ClipForge.

How it works

Stitch: download every clip, match size and frame rate, join them.
Smart cut: remove silences and dead air from each clip, then join.
Montage: fast cuts synced to a music track's beats, or to each clip's own audio. Add a track for beat detection.

Everything runs on your machine. Exports are saved to the folder set in Project & storage.
